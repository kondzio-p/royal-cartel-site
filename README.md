# Royal Cartel

Strona wizytówka dla klienta z Chojnic. Jedna strona z sekcjami, animacje przy przewijaniu i podstawy SEO.

Strona: https://royalcartelchojnice.pl

## Co jest w środku

- animacje GSAP i ScrollTrigger
- osobne zdjęcie hero na telefon i na desktop (WebP)
- dane strukturalne schema.org, Open Graph, sitemap i robots.txt
- polityka prywatności i strona 404

## Technologie

HTML, CSS, JavaScript, GSAP. Hosting na Vercel.
